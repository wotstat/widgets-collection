---
title: Универсальный турнирный
---
Виджет для отслеживания прогрессии в турнирах [challenge.tanki.su](https://challenge.tanki.su/challenges){target='_blank'}.

Сейчас поддерживаются:

- сумма лучших боёв по опыту, урону или уничтоженной технике;
- лучшая последовательная серия боёв по урону.

Неподдерживаемые форматы видны в списке, но недоступны для выбора.

> [!NOTE]
> Для работы виджета необходим мод [wotstat-widgets](https://github.com/WOT-STAT/wotstat-widgets/releases/latest){target='_blank'}. API турнира является источником значений, а сохранённая модом история используется только для определения танка. Если сопоставить бой не удалось, отображается `?`.
> Подходит и для игры и для OBS.

#### Цветовая палитра
Цветом акцента отображаются бои за текущую сессию.

#### График
График схематично отображает прошлые бои. Чем выше точка, тем лучше результат.
